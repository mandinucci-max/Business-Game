# Sicurezza

## Segnalare una vulnerabilità

Se trovi una vulnerabilità (accesso a dati di altri giocatori, creazione di Crediti dal nulla,
furto di account, exploit economici o tecnici), **non aprire una issue pubblica**.

Usa la segnalazione privata di GitHub: scheda **Security** del repository →
**Report a vulnerability**.

Indica, se puoi:

- cosa hai trovato e quale impatto ha;
- i passi per riprodurlo;
- la versione o il commit coinvolto.

Rispondiamo il prima possibile e ti teniamo aggiornato fino alla correzione.
Ti chiediamo di non divulgare la vulnerabilità finché non è stata corretta.

## Ambito

- Il motore di gioco, il server e la web app di questo repository.
- Exploit dell'economia di gioco (duplicazione di denaro, aggiramento delle regole, fughe di
  informazioni riservate) contano come vulnerabilità.

Il modello delle minacce e le contromisure sono descritti nel
[piano di implementazione](docs/PIANO_IMPLEMENTAZIONE.md) (§5).
